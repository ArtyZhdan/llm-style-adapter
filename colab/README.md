# Colab: обучение LoRA-адаптеров на T4

Здесь лежит всё для дообучения на бесплатном GPU Google Colab (T4, 16 ГБ) —
локальный скрипт `scripts/train_lora_3b.py` на 6 ГБ не тянет модели больше 3B,
поэтому эксперименты с 7B/14B выносим сюда.

## Файлы

- `colab_train_lora.ipynb` — готовый ноутбук: загрузите на
  https://colab.research.google.com (Файл → Загрузить ноутбук), выберите
  среду выполнения **T4 GPU** и запустите все ячейки. По умолчанию обучает
  **type1_full на Qwen2.5-7B** (все 160 примеров стиля 1); через константу
  `STYLE` доступны `type1` (первые 100, архивный состав) и `type2`.
- `README.md` — этот файл.

## Что делает ноутбук

1. Ставит зависимости точных версий локального рабочего окружения
   (unsloth + unsloth_zoo с PyPI, pinned; torch — системный Colab).
2. Принимает файлы данных, которые вы загружаете с компьютера (из `data/`
   проекта), и собирает ChatML. Состав зависит от `STYLE`:
   type1_full — все 160 (short+long) стиля 1; type1 — первые 100 short;
   type2 — все 160 стиля 2.
3. Обучает QLoRA с гиперпараметрами финальных адаптеров (r16/α32, LR 2e-4,
   4 эпохи, batch 1×8, seed 42). Чекпоинты — после каждой эпохи.
4. Скачивает архив с адаптером.

## Оценки времени на T4

| Модель | Контекст | Время на прогон (4 эпохи, 160 примеров) |
|---|---|---|
| Qwen2.5-7B | 2048 | ~30–50 мин |
| Qwen2.5-14B | 1024 (иначе OOM) | ~1,5–2 ч |

14B — максимум для бесплатного T4. Для неё в конфиге ноутбука
меняйте `MODEL_ID` и `MAX_SEQ_LENGTH = 1024`.

## После обучения (локально)

```bash
# распаковать архив в models/lora_type1_7b (вывод ноутбука type1_full), затем:
PYTHONIOENCODING=utf-8 STYLES=type1 \
  LORA_TYPE1=models/lora_type1_7b \
  OUTPUT_TYPE1=outputs_lora_type1_final_t02.txt \
  python scripts/generate_outputs.py
```

Финальные адаптеры проекта лежат в `models/lora_type1_7b` (вывод `type1_full`)
и `models/lora_type2_7b` (вывод `type2`, в папке — веса 3-й эпохи). Сравнение —
с `outputs_lora_type1_final_t02.txt` (24/25 чистых) и
`outputs_lora_type2_final_t02.txt` (~25/25): те же 25 тестовых
новостей, temp 0.2, seed 42. Проверяем: числа без выдумок, добивки/заголовки,
деградации на других примерах.

## Правила

- Коммитим сюда только скрипты/инструкции Colab; веса адаптеров в git не
  кладём (models/ в .gitignore) — передаём архивами.
- Ветка эксперимента не мержится в main без сравнения метрик.
